# Denki ⚡

แอป Android ส่วนตัวสำหรับติดตามการใช้ไฟรายวัน และเก็บค่าไฟแอร์จากพี่ชายพร้อมใบเสร็จ + QR พร้อมเพย์

- **จดมิเตอร์** หน้าบ้านด้วยมือ (ช่องตัวเลขใหญ่ วันเวลาตั้งเป็นตอนนี้ให้อัตโนมัติ)
- **นำเข้าภาพหน้าจอแอปแอร์** (Mijia) 1 ภาพ = ข้อมูลรายวันทั้งเดือน เลือกได้หลายภาพพร้อมกัน แอปอ่านตารางในเครื่องเอง (Google ML Kit) **ฟรี ไม่ต้องใช้เน็ต** แล้วให้ตรวจ/แก้ก่อนบันทึก
- **ภาพรวมรายวัน**: ทั้งบ้าน / แอร์ของฉัน / แอร์พี่ชาย / ส่วนอื่น เป็นหน่วยและบาท + ประมาณการบิลรอบนี้
- **ใบเสร็จ** เลือกช่วงวันที่ → รายละเอียดทุกบรรทัด + QR พร้อมเพย์ยอดเป๊ะ → ส่งเป็นรูปทาง LINE, ติ๊ก จ่ายแล้ว/ยังไม่จ่าย, แนบสลิป
- **บิล กฟน. จริง**: กรอกตัวเลข + ถ่ายรูปเก็บไว้ รอบไหนมีบิลจริง แอปจะใช้ตัวเลขจริงแทนค่าประมาณ
- **กราฟ** รายวัน/รายเดือน เทียบค่าเฉลี่ย วันสูงสุด/ต่ำสุด
- **แจ้งเตือน** ให้จดมิเตอร์ทุกวัน
- **อัปเดตในแอป**: ติดตั้งครั้งแรกครั้งเดียว ต่อไปเปิดแอปจะมีแถบเขียว "มีเวอร์ชันใหม่ — แตะเพื่ออัปเดต" (ฟรี ใช้ GitHub อย่างเดียว)

ข้อมูลทั้งหมดเก็บ **ในเครื่องเท่านั้น** (ไม่มีเซิร์ฟเวอร์) ควรกด **ตั้งค่า → สำรองข้อมูล** เป็นระยะ แล้วเก็บไฟล์ไว้ใน Google Drive / LINE Keep

## วิธีคิดเงิน

ถอดสูตรจากบิลจริงเดือน 09/69 (ประเภท 1.2, 454 หน่วย) ได้ตรงทุกบรรทัด:

| รายการ | คำนวณ | บาท |
|---|---|---|
| ค่าพลังงาน | 200 × 3.0000 + 200 × 4.1584 + 54 × 4.3583 | 1,667.03 |
| Ft | 454 × 0.1623 | 73.68 |
| ค่าบริการ | | 24.62 |
| VAT 7% | 7% × 1,765.33 | 123.57 |
| **รวม** | | **1,888.90** |

(200 หน่วยแรก 3 บาท และตั้งแต่หน่วยที่ 201 ลด 0.0634 บาท/หน่วย ตามหมายเหตุในบิล) อัตราทั้งหมดแก้ได้ในหน้า **ตั้งค่า**

**ค่าแอร์พี่ชาย** = หน่วยแอร์ × อัตราเฉลี่ยของบ้านในรอบบิลนั้น (ค่าพลังงานทั้งบ้าน ÷ หน่วยทั้งบ้าน)
+ Ft × หน่วยแอร์ + ค่าบริการตามสัดส่วนหน่วย + VAT 7%

- รอบบิลตัดตามวันจดมิเตอร์ (ค่าเริ่มต้นวันที่ 22)
- ถ้ารอบนั้นมีบิลจริงแล้ว ใช้ตัวเลขจากบิล ถ้ายังไม่มี ใช้เลขมิเตอร์ที่จด (และขยายเป็นทั้งรอบถ้ายังไม่ครบ) ใบเสร็จจะมีหมายเหตุว่าเป็นค่าประมาณ
- ถ้าช่วงวันที่คร่อมสองรอบบิล จะแยกคิดแต่ละรอบแล้วรวมกัน

## ติดตั้งครั้งแรก (ทำครั้งเดียว ฟรีทั้งหมด ทำผ่านเว็บได้)

ใช้แค่ GitHub (สร้างแอปด้วย GitHub Actions ซึ่งฟรีสำหรับ repo สาธารณะ) ไม่ต้องสมัคร Expo หรือบริการเสียเงินใด ๆ

1. **ตั้งรหัสผ่านกุญแจเซ็นแอป**: หน้า repo นี้ → Settings → Secrets and variables → Actions →
   New repository secret → ชื่อ `KEYSTORE_PASSWORD` ค่า = รหัสผ่านที่ตั้งเอง (ยาว ๆ เดายาก **และจดเก็บไว้**)
   > แอปทุกเวอร์ชันต้องเซ็นด้วยกุญแจเดียวกัน Android ถึงจะยอมให้อัปเดตทับได้
   > ถ้าลืมรหัสนี้จะอัปเดตทับไม่ได้ ต้องลบแอปแล้วติดตั้งใหม่ (กู้ข้อมูลจากไฟล์สำรองได้)
2. แท็บ **Actions** → **"สร้างแอป"** → Run workflow (หรือรอให้มีโค้ดใหม่เข้ามา) รอประมาณ 15–25 นาที
3. ในมือถือ เปิดหน้า **Releases** ของ repo นี้ (https://github.com/coolza254-lgtm/Denki/releases)
   → ดาวน์โหลดไฟล์ `denki-1.0.x.apk` ล่าสุด → ติดตั้ง
   (Android จะถามให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ครั้งเดียว)
4. (ไม่บังคับ) **ใส่ Claude API key** ไว้เป็นตัวช่วยสำรอง เวลาที่อ่านภาพในเครื่องไม่ออก:
   สมัครที่ https://console.anthropic.com → API keys → Create key → เติมเครดิตขั้นต่ำ
   แล้วในแอปไปที่ ⚙️ ตั้งค่า → วาง key → บันทึก (key เก็บแบบเข้ารหัสในเครื่อง)
   ใช้เฉพาะตอนกด "ให้ AI อ่าน" ประมาณ 1–2 บาทต่อภาพ ไม่ใส่ก็ใช้งานได้ปกติ

## อัปเดตแอป

- ทุกครั้งที่มีโค้ดใหม่เข้า branch หลัก GitHub จะตรวจโค้ด (typecheck + test) สร้าง APK ใหม่
  แล้วปล่อยเป็น Release อัตโนมัติ
- เปิดแอป → แถบเขียว **"มีเวอร์ชันใหม่ — แตะเพื่ออัปเดต"** → แตะ → แอปดาวน์โหลดเอง
  → กด **ติดตั้ง** ในหน้าต่างของ Android (ครั้งแรก Android จะให้อนุญาตแอปนี้ติดตั้งอัปเดต)
  หรือ ⚙️ ตั้งค่า → **ตรวจหาอัปเดต**
- ติดตั้งทับ ข้อมูลในเครื่องอยู่ครบ ไม่ต้องลบแอปเดิม
- APK สร้างสำหรับมือถือ 64-bit (ARM64) ซึ่งเป็นมือถือ Android เกือบทุกรุ่นในปัจจุบัน

## สำหรับนักพัฒนา

```bash
npm install
npm test           # ทดสอบสูตรคำนวณ, QR พร้อมเพย์, การคิดหน่วยรายวัน
npm run typecheck
npx expo run:android  # ต้องมี Android Studio ในเครื่อง
```

โครงสร้าง:

```
src/app/            หน้าจอ (Expo Router)
  (tabs)/           ภาพรวม, จดมิเตอร์, แอร์, ใบเสร็จ, กราฟ
  ac-confirm.tsx    ตรวจค่าที่อ่านจากภาพ
  bill-edit.tsx     บิล กฟน.
  receipt/          สร้าง/ดูใบเสร็จ
  settings.tsx
src/theme.ts        สี ฟอนต์ (Mitr) ตามโลโก้
src/components/     ชุด UI, ไอคอน, มาสคอต Spark, แถบเมนู
src/lib/
  tariff.ts         สูตรค่าไฟ (ขั้นบันได, Ft, ค่าบริการ, VAT, การแบ่งส่วน)
  usage.ts          เลขมิเตอร์ → หน่วยรายวัน
  calc.ts           รวมข้อมูล + รอบบิล + ประมาณการ
  promptpay.ts      QR พร้อมเพย์ (EMVCo)
  acOcr.ts          แปลงผล OCR เป็นตารางรายวัน (หา "kWh" → ค่า → วันที่)
  acImport.ts       OCR ในเครื่องด้วย Google ML Kit
  acExtract.ts      อ่านภาพด้วย Claude API (ตัวช่วยสำรอง)
  acCheck.ts        ตรวจค่าผิดปกติ
  db.ts             SQLite ในเครื่อง
  backup.ts         สำรอง/กู้คืน
  updater.ts        อัปเดตในแอปจาก GitHub Releases
plugins/            ตั้งค่า native (กุญแจเซ็นแอป)
tests/              unit tests (node --test)
```
